# 🎮 ROBOTONIO — Coin Game (Creative Programming 1 · Lesson 01)

Αυτό είναι το repository του **δικού σου** παιχνιδιού για το **Creative Programming 1 — Lesson 01: Coin Game** της χρονιάς 2026-27.  
Φτιάχτηκε από το template του ROBOTONIO — το περιβάλλον είναι ήδη έτοιμο, δεν εγκαθιστάς τίποτα.

## 🚀 Πώς δουλεύω

1. **Άνοιξε το Codespace:** πράσινο κουμπί **Code → Codespaces → Create codespace on main**.  
   Την πρώτη φορά αργεί 1-2 λεπτά (στήνεται ο υπολογιστής σου στο cloud). Αν κολλήσει σε «Connecting…», κάνε ανανέωση (F5).
2. **Γράψε κώδικα** στο `main.py`.
3. **Τρέξε το παιχνίδι σου** — στο τερματικό, μία εντολή:

   ```bash
   bash tools/run-game
   ```

   Το script χτίζει το παιχνίδι, καθαρίζει τυχόν παλιό server στην port 8000, ελέγχει ότι το build δημιουργήθηκε σωστά και ξεκινά τον web server.
4. Άνοιξε το **port 8000** από την καρτέλα **Ports** (εικονίδιο υδρογείου 🌐). Η πρώτη φόρτωση μπορεί να πάρει λίγο περισσότερο χρόνο.
5. **Άλλαξες κώδικα;** Σταμάτα τον server (**Ctrl+C**) και ξανατρέξε `bash tools/run-game` — ο browser δείχνει το *χτισμένο* παιχνίδι, όχι απευθείας το αρχείο σου.
6. **Πριν φύγεις:** αποθήκευσε τη δουλειά σου στο GitHub (**commit + push**) και κάνε **Stop Codespace**.

> **Μην εγκαθιστάς μόνος σου πακέτα** με `pip install` / `pip install -U` και μην αλλάζεις τα `.devcontainer/`, `requirements.txt` ή `tools/`, εκτός αν σου ζητηθεί. Οι εκδόσεις είναι κλειδωμένες ώστε όλα τα Codespaces να δουλεύουν με το ίδιο περιβάλλον.

## 🔍 Αν κάτι δεν δουλεύει

- **Κόλλησε στο “Loading, please wait…” ή κάτι φαίνεται χαλασμένο μετά από προηγούμενο build;**  
  Σταμάτα με **Ctrl+C** και τρέξε:

  ```bash
  bash tools/run-game --clean
  ```

- **Το παιχνίδι δεν ανοίγει;** Καρτέλα **Ports** → βρες το 8000. Το `run-game` προσπαθεί να το κάνει **Public** αυτόματα. Αν δεν τα καταφέρει: δεξί κλικ στο 8000 → **Port Visibility → Public**.
- **Θες να δεις λάθη (Tracebacks) ή τα `print`;** Στη σελίδα του παιχνιδιού: **F12 → Console**.
- **Γκρίζα οθόνη ή το παιχνίδι δεν προχωρά;** Έλεγξε πρώτα ότι δεν έσβησες το `import pygame`, το `asyncio.run(main())` ή το `await asyncio.sleep(0)` από το `main.py`.
- Αν το script γράψει ότι το `.tar.gz` δεν δημιουργήθηκε σωστά, χρησιμοποίησε πρώτα το `--clean`. Αν συνεχίζεται, ενημέρωσε τον καθηγητή αντί να αλλάξεις αρχεία του περιβάλλοντος.
